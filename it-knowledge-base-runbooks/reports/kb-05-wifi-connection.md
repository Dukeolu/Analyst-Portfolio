# Connecting to the Corporate Wifi Network

**Applies to:** All office locations
**Estimated time to fix:** 2–5 minutes
**If this doesn't work:** Skip to "Still stuck?" at the bottom.

---

## First-time connection

1. From your device's wifi settings, select **MeridianCorp** (not MeridianGuest — that network is for visitors and has no access to internal systems).
2. Enter your regular network username and password when prompted.
3. If asked to trust a certificate, tap **Trust** or **Accept** — this is expected and confirms you're connecting to the real corporate network, not an impostor network with the same name.
4. Your device should now show "Connected" and stay connected automatically on future visits to any Meridian office.

## "Connected, but no internet"

This is almost always a certificate or clock problem, not a real connectivity problem:

1. Check that your device's date and time are set to automatic — a device with the wrong date can fail wifi authentication in a way that looks like "no internet" instead of an obvious error.
2. Forget the MeridianCorp network on your device and reconnect from scratch — this clears a stale or expired certificate, which is the most common cause of this specific symptom.

## Keeps disconnecting / weak signal in a specific area

Some areas of the warehouse floor have known weaker coverage due to the metal shelving. This is a known layout issue, not something a KB article can fix — if you're in the warehouse and losing signal regularly, submit a ticket noting the specific location so it can be tracked for the next access-point placement review, rather than treated as a one-off.

## Still stuck?

**Submit a ticket** and include:
- Which building/floor you're in
- Whether this is a new device or one that worked before and stopped
- What you see exactly ("no networks found," "connected but no internet," "keeps disconnecting," etc.) — the fix is different for each of these
